# LLM providers

Chat replies are generated by the **active** LLM provider for the workspace.

## Admin → Providers

Add or edit providers with:

| Field | Purpose |
|-------|---------|
| Name | Label in Admin |
| Kind | `openai`, `deepseek`, or `custom` |
| Base URL | API root; QueChat calls `/chat/completions` |
| Model | Model id for that provider |
| API key | Stored in Postgres; masked in the UI |
| Active | Exactly one active provider powers the widget |

## Presets

Common presets include:

- DeepSeek
- OpenAI
- Groq
- OpenRouter
- Together
- Ollama
- Custom (any OpenAI-compatible endpoint)

## Seeding

If `DEEPSEEK_API_KEY` is set when the database is seeded, a DeepSeek provider can be created and marked active automatically.

## Operational notes

- Rotate provider API keys if they leak.
- Keep only the intended provider **active**.
- Provider create/update/delete events are written to audit logs.
- Chat failures (wrong key, bad base URL, model errors) appear in Logs and Analytics.
